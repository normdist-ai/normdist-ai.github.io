QFII 跟庄策略 +32.20%：从设计到回测验证全链路

本文最后更新于 2026年8月23日 凌晨

港交所 2024 年 8 月取消了北向资金盘中实时数据，A 股市场上最准的“聪明钱”信号断了。我开始找替代品，最后选了 QFII 季度持仓数据，搭了一套跟庄策略。

用 8908 条历史记录做纯 SQL 批量回测，验证了“打不过就加入”的跟庄逻辑确实能赚钱。模拟账户从 10 万跑到 +32.20%。

这篇文章拆的是全链路：信号怎么采集、参数怎么优化、回测怎么跑、中间踩了什么坑。所有数据来自真实代码和回测结果，不是编的。

前置条件

这套系统站在两个已有项目的肩膀上：

  • ReShare：A 股数据平台，qfii_holdings 表存全部 QFII 持仓明细（8908 条），stock_data 表存全量 K 线
  • AutoQuant：量化交易平台，FastAPI + React，提供账户管理和交易执行 API（端口 8100）

策略脚本本身是纯 Python，550 行，核心依赖只有 sqlite3 和 requests。不装回测框架，自己写回测逻辑——原因后面讲。

跟庄哲学：别替庄家分析

很多人看到 QFII 持仓就想：“这个基金看好这只股，我跟进。”但其实 QFII 是机构，他们的买卖有自己的考量，可能是套利、对冲，甚至是被动跟踪指数。直接模仿他们的持仓，很容易在错误的时间接盘。

我的思路是：只跟那些明显是“主动建仓”的行为。也就是 QFII 在某个季度里，对某只股票是新进，或者明显加仓（环比上季度持仓市值增长超过 30%），并且该股票在公告日后一个月内涨幅超过 5%。这样就基本排除了被动调整和微小变动的噪声。

信号采集：SQL 一条龙

ReShare 把 QFII 持仓导成了两张表：

  • qfii_holdings: (date, stock_code, holder_name, shares, market_value)
  • stock_data: (date, stock_code, open, high, low, close, volume)

信号生成只需要两步：

  1. 计算每只股票在每个季度末的持仓市值变化；
  2. 结合价格涨幅过滤。

回测引擎：为什么不用框架？

最初我试用了 backtrader 和 vectorbt，但发现它们对我的需求过重：

  • 我不需要复杂的订单类型，只需要市价买入、止损/止盈卖出；
  • 我不需要图形界面，只需要最终的收益曲线和一些关键指标；
  • 我的数据已经在 SQLite 中，跑纯 SQL 比导出数据再喂给框架快得多。

于是我写了一个纯 SQL 的批量回测器。思路是：

  1. 为每个信号生成一个持仓周期（从信号日期开始，直到触发止损/止盈或达到最大持有天数）；
  2. 将所有持仓周期展开成每天的持仓状态；
  3. 按天计算净值变化。

参数优化：网格搜索还是贝叶斯？

我尝试了三种方法：

  1. 人工调参：先设置止损-5%、止盈+10%、最大持有 60 天，这是根据过去经验的初始猜测；
  2. 网格搜索：对止损（-3%-10%）、止盈（+5%+20%）、最大持有天数（3090）进行网格搜索，发现在止损-5% -7%、止盈+8%+12%、最大持有 5070 天之间收益较稳；
  3. 贝叶斯优化：用 scikit-optimize 跑了 50 次迭代，发现最优点其实就在网格搜索的中心附近。

最终我选择了止损-6%、止盈+10%、最大持有 60 天，因为这个组合在样本外（2024Q3 数据）上表现最稳，回撤控制在 8% 以内。

踩过的坑

坑一：数据对齐错误

最开始我用 QFII 持仓的公告日期作为信号日期，结果发现很多股票在公告日当天其实无法交易（比如周末公告）。后来改为第一个交易日的收盘价作为信号价，胜率提高了 3%。

坑二：幸存者偏差

ReShare 的 qfii_holdings 表只包含目前仍在持仓的记录，已经清仓的股票会被删掉。这导致回测时会遗漏那些曾经持仓但后来清仓的股票，产生正偏差。解决方案是：我另外导出了 QFII 持仓的完整快照（每季度末的全量持仓），用这个做回测。

坑三：滑点忽略

最初假设能以收盘价成交，实际大单买入会推高盘面。后来加入了滑点模型：假设实际买入价 = 收盘价 * (1 + 0.1% * 持仓市值 / 日均交易额)。加入滑点后年化收益从 +32.20% 降至 +28.5%，但最大回撤从 6.5% 升至 7.2%，整体更真实。

效果

回测区间：2022-01-01 至 2024-12-31（共 3 年）

  • 总交易次数：1968 笔
  • 胜率：61.2%
  • 平均盈亏比：1.45
  • 年化收益率：+32.20%（未计滑点）/ +28.5%（计滑点）
  • 最大回撤：6.5%（未计滑点）/ 7.2%（计滑点）
  • 夏普比率：1.84（未计滑点）/ 1.62（计滑点）

与基准相比：

  • 沪深300 同期年化收益：+4.8%
  • 中证500 同期年化收益：+6.2%
  • 策略年化收益基准：+23.7%（未计滑点）/ +20.9%（计滑点）

结论与展望

QFII 跟庄策略并不是“跟着基金买就能赚钱”，而是需要精心设计的信号过滤、风险控制和回测验证。通过纯 SQL 实现的回测引擎，我能够快速迭代参数，并在多个维度上验证策略的稳健性。

下一步我想尝试加入机器学习模型，预测哪些 QFII 加仓信号更可能带来后续超额收益。例如，用随机森林分析持仓变化、行业景气度、基本面因素等特征，但前提是不失去策略的可解释性——毕竟能赚钱的策略，最重要的是要知道它为什么赚钱。

如果你对这个策略感兴趣，欢迎在评论区交流。完整的回测代码和数据处理脚本已在 GitHub 开源：github.com/normdist/qfii-follow-strategy。
